# 复习与近义词方案

词义、句子填空和拼写共用一个入口，但各自保存 FSRS 卡片。队列只使用开启的题型，优先处理到期及重学任务；新能力间隔至少 20 分钟引入，每轮同一词仅出现一次。20 分钟是产品的初始参数，并非已经验证的最优学习间隔；后续可根据实际使用调整。

填空中的有效同义替代不证明目标词已经掌握，因此不加分也不记错，保留原有熟练度，10 分钟后补测目标词。提示逐步增加：释义、首字母、揭晓；前两级帮助下答对计为 Hard，直接揭晓计为 Again。判定优先复用本地候选和缓存，必要时才请求简短的上下文判定。

## 近义词分组建议（尚未实现）

适合做“辨析关系”，不建议把相似词的复习进度合并，也不建议初次学习时连续集中呈现许多相近词。相关实验发现语义相关词更容易出现组内混淆，间隔呈现可以减少这类干扰；不能据此断言分组在所有任务中都更差。[Nakata 与 Suzuki 的实验](https://www.cambridge.org/core/journals/studies-in-second-language-acquisition/article/effects-of-massing-and-spacing-on-the-learning-of-semantically-related-and-unrelated-words/F58BA8D70385603B9C42E408BFCB8A10)

建议先只在已经收录的词之间建立小组：按词性和具体义项关联，每组 2–4 个词，展示共同含义、语气或搭配差异以及对比例句。AI 建议可确认、移除和缓存，不自动把整个词条视为所有语境下的同义词。初学词继续单独复习，已有基础后才偶尔加入对比题；各词、各能力仍独立调度。

当前版本实现的是填空的同义替代判定，还没有自动分组界面。
