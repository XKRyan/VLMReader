# VLMReader 0.6.16

本次合并 0.6.12 之后的本地改进，发布 Windows x64 安装版、便携版和源码。

- 丰富离线英英释义，增加 Wiktionary 补充词典、词典查询历史与来源排序。
- 支持导入 MDX 词典，包括常见压缩、编码与索引加密格式；用户词典不随安装包分发。
- 优化词本分类、生词标记、批注、选区与页面布局，改进复习提示和语音队列。
- 保留独立的回忆、拼写、填空与造句复习安排，以及键盘操作和阅读批注分享。

验证：140 项单元测试通过，TypeScript 与前端构建通过；重新构建的程序经过词本、复习、重启保存与离线朗读界面检查。安装包和便携包包含离线词典、语音模型及第三方许可，不包含个人书籍、词本、批注、API 密钥或导入的商业词典。

安装前请关闭 VLMReader，选择原程序目录可继续使用原有 data。安装和卸载保留个人 data。此 Windows 版本没有发布者代码签名；系统可能提示未知发布者。仅支持 Windows x64。
