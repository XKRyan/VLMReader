# MemReader

Windows 阅读器：本地文档、离线词典、双语朗读、批注与间隔复习。支持简体中文 / English。

## 启动

双击 `MemReader.lnk`，或运行 `release\win-unpacked\MemReader.exe`。程序无需安装。不要单独移走 exe；它需要同文件夹中的资源。首次启动可阅读欢迎文档。

## 使用

- 导入 PDF、EPUB、DOCX、TXT、Markdown 或 HTML；支持拖入文件、搜索、目录、阅读进度、收藏、书签与打印。PDF 原版和文字模式均连续滚动，各页自然衔接，跨页不会跳到页首；EPUB 支持滚轮翻页。
- 鼠标选中词或句子，右侧显示译文。单词默认保存释义与原句；句子默认不自动加入生词本，仍可翻译、批注或手动保存。自动收集句子和悬停查词可在设置中开启。
- 选中文字后点击“添加批注”，保存高亮和自己的理解。批注侧栏支持定位原文、编辑与删除；跨重启保留，删除不改动文档内容。
- 英汉查询使用 ECDICT，汉英查询使用 CC-CEDICT；保留完整词条与英文释义。专业词、短语或词典未收录的内容可使用 API。
- 句子翻译在“偏好设置 → 翻译服务”填写 DeepSeek API 密钥后启用。默认模型名为 `deepseek-flash`，接口地址和模型名称可修改。密钥使用 Windows 加密存储，不会出现在资料导出文件中。
- 底部播放按钮朗读当前页面或章节；右侧扬声器朗读所选内容。支持暂停、停止、0.50–3.00 倍连续调速并保持音高，默认自动接续下一页或章节。Kokoro 在本机生成语音，无需下载每段音频；英文数字按英文发音。阅读时后台提前准备语音，首次播放短暂缓冲，句子共享连续音轨。完成的音轨永久保存在 `data\audio`，退出或重启后直接复用；改变倍速不重新生成。停止播放后可在后台完成缓存，提前退出时已完成句子也会保留。96 kbps 单声道 MP3 约 0.7 MB / 分钟，一小时约 43 MB；完整音轨保存后去除重复的临时句子文件。
- 生词本的“添加单词”可以单独输入中英文词语，由离线词典自动补全释义，再保存可选原句，无需 API。词典未收录时可手动填写释义。
- 生词本可以编辑完整译文、查看原句、回到来源、补译句子、暂停复习和导出 CSV/JSON。勾选条目后点击“删除所选”即可批量删除；表头复选框全选当前搜索 / 筛选结果，换筛选条件会清空选择。确认后同时删除所选条目及其复习记录，取消则保留。每行及详情顶部也可单独删除。
- 复习时先回忆再显示答案，用“重学 / 困难 / 记得 / 轻松”评分。单词支持词义回忆、原句填空和拼写练习；句子单独支持“回忆句意”和“关键词填空”，用自己的话解释意思即可，不要求逐字背诵。填空只遮住一个词或短语，可在生词本详情指定目标，留空则自动选择关键词。复习页面可筛选单词或句子；FSRS 根据评分安排下次复习，默认目标保持率 90%。主动回忆与间隔练习有研究支持，但没有适合所有人的唯一最优方法。
- 四种阅读主题，字号、行距、宽度与字体可调。偏好设置中分别选择“界面字体”和“正文字体”，可输入已安装字体的名称。DOCX、EPUB、TXT、Markdown 和 HTML 使用正文字体。PDF 顶部点击“文字模式”可修改字体和字号；“原版 PDF”保留原布局与原字体。文字模式只重排提取的文字，不保留图片、复杂公式或多栏布局，扫描 PDF 仍需先 OCR；设置中可即时切换简体中文 / English，语言选择会保存。

“偏好设置 → 阅读外观 → 界面字号”可调导航、按钮与面板文字，范围 13–22px，默认 16px（比上一版增大约 23%），关闭后会记住。正文字号单独设置；原版 PDF 保留原字体与取词位置。

快捷键：Ctrl+O 导入、Ctrl+F 文内搜索、Ctrl+Space 暂停 / 继续朗读、F11 全屏；复习时 Space 显示答案，1–4 评分。

## 数据与限制

个人资料位于 `data`。`data\books` 存放导入的文档副本，`library.json` 存放进度、生词与复习记录。移除书架文档不影响原始文件和已收集的生词。

“立即备份”和 JSON 导出保留阅读记录与生词；迁移全部文档时请复制整个 `data` 文件夹。加密 API 密钥跨电脑需要重新填写。

扫描 PDF 可以查看，但需要先经过 OCR 才能划词、搜索或朗读。旧版 `.doc`、DRM 加密电子书及复杂 Word 版式不在当前支持范围；DOCX 按阅读版式显示。打印功能打印当前可见文档视图。离线词典不替代上下文翻译；没有有效 API 密钥时可手动保存为待翻译，之后补译。

词典、模型、依赖许可和研究链接见 `assets\ATTRIBUTION.txt` 及随程序附带的许可文件。

## 开发与验证

需要 Windows x64、官方 Node.js 24、pnpm 和 Python 3.12+。源码仓库不包含大词典、模型、运行时、构建产物或个人资料。首次构建：

```powershell
pnpm install
python scripts/prepare_assets.py
node scripts/prepare_runtime.cjs
pnpm build
pnpm start
pnpm package
```

资源准备只需首次执行，之后复用本地文件。打包后自动校验并恢复官方 Electron 运行时字节，窗口与快捷方式使用独立应用图标。Rollup 使用官方 WASM 包，兼容限制原生构建模块的 Windows 应用控制策略。

运行 `pnpm test` 检查词典、资料持久化、FSRS、翻译与持久语音缓存；`node tests/vocabulary-ui.cjs` 验证批量删除和字号，`node tests/annotations-ui.cjs` 验证手动词典添加、批注与句子默认不收集，`node tests/ui-smoke.cjs` 验证桌面功能，`node tests/reader-regression.cjs` 验证真实鼠标取词、字体与连续滚动，`node tests/speech-continuity.cjs` 验证连续音轨、停止重启、倍速和实际应用重启后的缓存复用。界面测试使用独立资料夹，不会写入个人资料；可设置 `MEMREADER_EXE` 测试打包程序。合成测试文档可通过 `scripts/create_fixtures.py` 生成（需要 reportlab 与 python-docx）。
